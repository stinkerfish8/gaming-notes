## Columns Guide <a id="columns-guide"></a>

- **Ingredient:** English name of the ingredient.
- **Base ID:** Hexadecimal form identifier of the item in the game data (`xx` or `FE` prefixes indicate add-ons/Creations depending on load order).
- **Primary / Secondary / Tertiary / Quaternary Effect:** The four alchemy effects of the ingredient, with any magnitude, duration, or value multipliers shown in parentheses.
- **Value:** Base gold value of the ingredient.
- **Weight:** Weight in game units.
- **Merchant Avail.:** Typical availability from merchants.
- **GardenHF:** Number of plants yielded when grown in a *Hearthfire* garden/greenhouse plot (where applicable).

## Localized & Original Name Lookup <a id="localized--original-name-lookup"></a>

### Find the localized name (Italian) from the English name

1. Open the in-game console using **`\`** (or **`~`** / **`º`** depending on your keyboard layout).
2. Type `help "<one word of the English name>" 4` and press **Enter** (e.g., `help "Nirnroot" 4`).
3. Use **`Page Up`** and **`Page Down`** (`Pag Su` / `Pag Giù`) to scroll through multiple lines of output.
4. Press the console key again to close it.

### Find the original name (English) from the localized name

1. Open the console and type `help "<word in the localized name>" 4`, then press **Enter** (e.g., `help "Cuore" 4`).
2. Read the item's **FormID** (hexadecimal code) from the console output.
3. Look up that **FormID** on the UESP wiki to see the matching English ingredient name, or match the ingredient's **4 alchemy effects** against the tables in this file.
4. Use **`Page Up`** and **`Page Down`** to scroll and press the console key again to close it.
